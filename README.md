# ChatGPT-review-analysis

# ChatGPT Reviews Analysis

# Project Overview
This project analyzes 2000+ ChatGPT user reviews from Play Store using Python to understand user sentiment.

# Dataset
File: chatgpt_reviews.xlsx
Columns: Review Text, Ratings, Date
Size: 1000+ reviews

# Tools Used
- Python, Pandas
- Matplotlib, Seaborn
- TextBlob for Sentiment
- WordCloud

# Key Visualizations
1. Rating Distribution - 5 star high
2. Sentiment - 74% Positive
3. WordCloud - love, helpful, great
4. Review Length vs Rating
5. Trend over Time

#Insights
- Users love ChatGPT for coding and writing help
- Major complaints: App slow, paid limit, bugs
- Suggestion: Improve speed and free limit

# How to Run
Open Copy of chatgpt_reviews_analysis.ipynb in Google Colab and run all cells.
